# Chapter 8 — The Hardware Checklist

This chapter is meant to be printed, folded, and lived next to while the project happens. It collects every check and every note worth writing down, in the order the project actually offers them. A pencil is fine; the point is making the plan concrete on paper where momentum can find it.

## The pre-flight list (before chapter 1)

Do these with the laptop as it is right now:

- [ ] Model name and year written down (underside label).
- [ ] 64-bit CPU confirmed (chapter 3's rule: ~2008 or newer).
- [ ] RAM confirmed: 1 GB / 2 GB / 4 GB / 8 GB / more.
- [ ] Drive type known: HDD (spins) or SSD (silent).
- [ ] Screen lights and hinges hold firmly.
- [ ] Keyboard: every letter works badly-but-works, or the spare-USB-keyboard plan is known.
- [ ] Charger present and intact (fewer sparks than a rogue firework).
- [ ] Battery holds *some* charge, or the always-plugged-in plan is confirmed.

## The rescue-drive record (chapter 1)

- [ ] External drive plugged in directly (no hub).
- [ ] Rescue folder created with default name + category subfolders.
- [ ] Photos copied and spot-checked.
- [ ] Documents, Downloads, Desktop copied and spot-checked.
- [ ] Bookmarks exported to HTML and spot-checked.
- [ ] Passwords exported to CSV and spot-checked, then stored safely.
- [ ] Email exported (if the desktop-mail case applies).
- [ ] Keys and serial numbers written down.
- [ ] Backup verified after unplug-and-replug.

## The wipe-day record (chapter 2)

- [ ] Backup verified (yes, again).
- [ ] Objectives unlinked: Microsoft/Apple account removed device, services signed out.
- [ ] Everything unplugged: drives, printers, phones, nothing trusted attached.
- [ ] Wipe method chosen and executed (revive: installer erase; donate: reset or live-USB method).
- [ ] SSD? (encrypt-then-erase noted as the airtight version).

## Install-day record (chapters 3–4)

- [ ] ISO downloaded from the official site: Mint / Lubuntu / MX.
- [ ] (Optional) checksum compared and matched.
- [ ] USB stick flashed with Etcher or Rufus; stick ejects politely.
- [ ] Boot-menu key noted: ______ (F12 / F9 / Esc / F2 by brand).
- [ ] Live mode tried; Wi-Fi connected; touchpad bearable.
- [ ] User name and password written down (twice, once on paper and once in the password manager).
- [ ] Disk-encryption password (if yes was chosen): written down in two places.
- [ ] First-boot updates applied.
- [ ] Lid-close behavior set to taste.

## The AI record (chapter 5)

- [ ] Ollama installed; version prints.
- [ ] Model downloaded: _______________ (name as typed).
- [ ] Model size ≤ half the RAM.
- [ ] First chat happened; response speed honest.
- [ ] `ollama list` output noted (disk space per model).

## The station record (chapter 6)

- [ ] One and only one job assigned: writing / printing / local chat.
- [ ] Mains power: permanent home found.
- [ ] Vents wiped (soft cloth, dry).
- [ ] Auto-updates left on defaults.
- [ ] Print test page (if printing job).
- [ ] Chat card taped to the shelf (commands + Wi-Fi name).
- [ ] Monthly rescue-drive copy ritual on calendar.

## The retirement record (chapter 7)

- [ ] Checklist above mostly failing → retirement confirmed as the kind end.
- [ ] Path B wipe completed and verified.
- [ ] Accounts unlinked, authorizations removed.
- [ ] Serial photographed for personal records, then removed-for-public-sharing ruled.
- [ ] Charger included with donation.
- [ ] Swollen battery? → battery retailer or e-waste drop, never mail.

## When the RAM upgrade is the one cheap miracle

One allowance for hope: on many 2010–2015 laptops, RAM is a removable stick, and moving from 2 GB to 4 GB (or 4→8) costs roughly $10–25 used (prices approximate, October 2026) and 10 gentle minutes: power off, unplug, small Phillips screwdriver, click, close. It lifts even Lubuntu from "polite" to "smooth." If the pre-flight list says 2 GB soldered, skip this and go to chapter 7 without grief.

That is the whole checklist. If most boxes get to be ticks, the project deserves the week's evening; if they un-tick themselves, chapter 7 keeps the goodbye warm.
